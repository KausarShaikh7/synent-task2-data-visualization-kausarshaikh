# Task 2: Data Visualization

## Problem Statement

The objective of this task is to visualize patterns in the Iris dataset using different types of charts and compare its features to gain a better understanding of the data.

## Dataset Details

- **Dataset:** Iris Dataset
- **Source:** Kaggle
- **File:** `IRIS.csv`
- **Domain:** Data Analysis

The Iris dataset contains measurements of iris flowers along with their species. The main features include sepal length, sepal width, petal length, and petal width.

## Approach

The following steps were performed using Python, Pandas, and Matplotlib:

1. Loaded the Iris dataset and examined its basic structure.
2. Created a bar chart to show the number of samples for each Iris species.
3. Created a histogram to visualize the distribution of Sepal Length.
4. Created a scatter plot to compare Petal Length and Petal Width.
5. Used the visualizations to compare features and identify patterns in the dataset.

## Visualizations

### 1. Number of Samples per Species

A bar chart was created to compare the number of samples belonging to each Iris species. The chart shows that the dataset contains a similar number of samples for each species.

### 2. Distribution of Sepal Length

A histogram was used to understand how Sepal Length values are distributed across different ranges and which ranges occur more frequently.

### 3. Petal Length vs Petal Width

A scatter plot was created to observe the relationship between Petal Length and Petal Width. The plot shows that these two features generally have a positive relationship.

## Key Insights

- The three Iris species are similarly represented in the dataset.
- Sepal Length values are distributed across a range of measurements, with some ranges occurring more frequently.
- Petal Length and Petal Width show a positive relationship, making these features useful for comparing Iris flowers.

## Output

The visualizations provide a clear understanding of feature distributions, sample representation, and relationships between important features in the Iris dataset.
